# ThoughtScape: new DFG proposal and companion paper (draft v1, 16 Nov 2026)

New research-grant proposal and a companion manuscript built on the ThoughtScape platform
(`github.com/victordeman/thought-scape`, inspected at commit `793795a`), written in response to the
reviews of the rejected DFG proposal OB 607/1-1. This folder is unrelated to the privacy toolkit in the repository root.

| Path | Contents |
|---|---|
| `proposal/dfg-proposal-thoughtscape.{md,docx,pdf}` | Project description in DFG section structure (13 pages in Arial 11, line spacing 1.2) |
| `proposal/reviewer-response-matrix.{md,docx,pdf}` | Each criticism of the reviewers mapped to the change and the section that answers it |
| `paper/thoughtscape-paper.{md,docx,pdf}` | System and measurement-validity paper with a stress test of the shipped metrics |
| `experiments/` | Probe set, scripts and raw results of the stress test (reproducible) |

## Read before use

* **No student data exist in any of this.** The only empirical result is a stress test (n = 22) of the similarity step on probe items that an AI assistant wrote and no domain expert has yet validated.
* Items in `[square brackets]` must be supplied or confirmed by the applicant: partner courses and letters, own publications, eligibility route and host statement, ethics bodies, hosting region of the production database, personnel rates, DFG resubmission rules.
* Budget figures are indicative and must be recomputed with DFG form 60.12 for the start year.
* The proposal and the paper both carry a generative-AI disclosure, as DFG requires. Verify every claim, number and reference before submission.
* The DFG page limits and section structure were read from form 54.01 (current version listed by the DFG as 06/26) through a summarising tool; check them against the official PDF.
